# AGENTS.md

## General
- Understand the existing code before making changes.
- Prefer the smallest, safest change.
- Match the project's coding style and architecture.
- Reuse existing code instead of creating new abstractions.

## Code
- Write clean, readable, and maintainable code.
- Avoid unnecessary complexity and dependencies.
- Handle errors properly; don't swallow exceptions.
- Remove unused imports, variables, and dead code.

## Quality
- Consider edge cases.
- Keep performance in mind.
- Don't break existing functionality.
- Update tests and documentation when needed.

## Communication
- Briefly explain your approach before major changes.
- Ask for clarification if requirements are ambiguous.
- Never assume missing requirements.
